# 프롬프트: 외부 원천 점검표

[docs/design/multi-source.md](../docs/design/multi-source.md) 1단계. 아래를 내부 AI에 붙여 넣는다.
결과 표는 업무 정보이므로 사내에만 둔다. 이 저장소에 커밋하지 않는다.

```
우리 Foundry Project로 가져오는(또는 가져올) 외부 데이터 원천을 모두 점검해 표 1개로 줘. 코드 금지, 데이터 조회만.
원천마다 1행. 칸:
1. 원천 dataset 경로
2. 행 수, 컬럼 수
3. 갱신 방식(SNAPSHOT/APPEND)과 최근 갱신 주기 (History 기준)
4. 키 후보: null 0건이고 중복 0건인 컬럼 또는 컬럼 묶음. 없으면 "없음"
5. 키 후보별 null 건수, 중복 건수
6. 동기화마다 바뀌는 기술 컬럼 (동기화 시각, 적재 ID 등) 추정
7. 추천 모드: 키 후보 있으면 ROW, 없으면 WHOLE
8. 모르는 것 (나에게 물을 것)
표를 보여 준 뒤 8번 질문만 한 번에 모아서 물어. 추측 금지.
```
